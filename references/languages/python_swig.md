## Clarify the three facades (common confusion)

| Name | Binding | Source |
|---|---|---|
| `backtrader` | native Python Backtrader (oracle) | external package |
| `back_trader` | **pybind11** facade | `python/back_trader/`, `bindings/pybind11/` |
| `back_trader_swig` | **SWIG** facade (this target) | `bindings/swig/interface/back_trader_swig.i`, `python/back_trader_swig/` |

**python_swig is NOT "replace `import backtrader` with fork `back_trader`".** It
replaces it with `back_trader_swig` (`import back_trader_swig as bt`). The generator
(`scripts/run_iter55_python_swig_strategies.py:91-120`) rewrites all three forms:
`import backtrader` / `import back_trader` → `back_trader_swig as backtrader`, and
`from backtrader...` / `from back_trader...` → `from backtrader_swig...`. It also maps
`pybind_mirror` → `python_swig_mirror`, `pybind11_result.json` →
`python_swig_result.json`.

- Sample: `languages/python_swig/bb_adx_strategy.py` (8.22 KB), generated by
  `benchmarks/tools/create_python_swig_strategy_wrappers.py --write --force`, marked
  "DO NOT EDIT BY HAND", with `__BT_SWIG_ORIGINAL_FILE__` pointing at the original.
- Runner: `run_python_swig_strategy_backtests.py`, `run_iter55_python_swig_strategies.py`.

## Real API mapping

Nearly line-identical to native Python: `bt.Strategy`, `bt.indicators.*`,
`self.data.close[-1]`, `buy()/sell(exectype=bt.Order.Stop,price=...)/close()`,
`bt.analyzers.TotalValue/SharpeRatio/Returns/DrawDown/TradeAnalyzer`,
`pd.read_csv` + `bt.feeds.PandasData` — only the import name changes.

## Build / run (no compile step)

```bash
python3 scripts/run_iter55_python_swig_strategies.py \
  --generate --run --force --workers 8 --timeout 600 \
  --abs-tol 1e-6 --rel-tol 1e-6
```
Child runner: `preload_swig_package()` prepends
`tests_python_swig/subprocess_support` to `sys.path`, calls
`load_package(Path(build_dir), Path(repo_root))` to assemble
`back_trader_swig._native` + `_generated` proxies, then `runpy.run_path(script)`,
`os._exit(code)`. Env: `PYTHONPATH` prefixed `<repo>/python`,
`BACK_TRADER_REPO_ROOT`, `BACK_TRADER_SWIG_BUILD_DIR` (default
`<repo>/build_swig_python/bindings/swig`), `BACKTRADER_DATA_DIR`/
`BACK_TRADER_DATA_DIR`.

## Audit flow (three-way, not just pybind11)

`run_iter55_python_swig_strategies.py:292-331` compares `python_swig_result.json`
against THREE baselines: native `py`, `pybind11_result.json`, and `cpp_result.json`.
- Field sets must be exactly equal (else `field_error`).
- Numeric: `max(abs_tol, rel_tol*max(|a|,|b|,1))`, default 1e-6 each.
- `null` matches only `null`; strings/bools exact; `finite_or_none` normalizes
  NaN/Inf → None.
- States: `matched/field_error/value_mismatch/run_failed/timeout/missing_output/
  generation_skipped`.

Hard constraints (TODO-python_swig.md):
- Strategy must implement its own class — never call a concrete strategy implementation
  from the SWIG facade.
- Must use exposed `Cerebro`/`Strategy`; no hand-written broker/feed/analyzer engine.
- No fallback to pybind11, native `backtrader`, C++ executable, or pre-generated JSON.
- Results aligned with Python/pybind11/C++ benchmark outputs at 1e-6.
- Failures go to a fix record; never edit result files.

## python_swig-specific notes

- This is an API-compatibility audit of the SWIG binding, not a genuinely different
  language port. Treat it as such in reports — do not claim it proves a new language.
- `extract_last_json(output)` scans stdout from each `{` via `raw_decode` and takes the
  LAST dict; `normalize_payload` writes `results/python_swig_result.json`
  (`ensure_ascii=False, indent=2, sort_keys=True`).
- Sample hardcodes `engine="python_swig"`.
- Distinguish from pybind11 local audit (`pybind11-strategy-local-audit.md`) — that
  document describes a different facade.
